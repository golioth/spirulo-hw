# Spirulo

## What it is

Spirulo is a small, round NFC spiral-antenna PCB designed to mate with Golioth's "phial" board (the phial project was formerly named "pilulith" — see commit d9261b1: "add two cutouts to match phial (nee pilulith)"). The board's central feature is a copper spiral coil drawn directly in the PCB copper (the `20mm_NFC_Spiral` footprint), i.e. an NFC antenna, plus a coin-cell battery holder and two small pin connectors. STEP exports of this board are used as 3D models in the companion phial-hw repo.

The exact system-level function of the board is [UNKNOWN] — this repo contained no documentation until this README was added (October 2026), and the design files alone do not state how the coil, battery, and connectors are used together.

## Hardware summary

Everything below is taken from the schematic and PCB files (Rev B state):

- Copper spiral coil / NFC antenna: footprint `20mm_NFC_Spiral`, net `COIL`
- BT101: Keystone Electronics 112TR SMD coin-cell battery holder (SnapEDA PN "112", a low-profile holder for a ~12 mm coin cell; the exact cell part number is not recorded in the design files [UNKNOWN])
- J101: 1x02 pin connector (`Connector:Conn_01x02_Pin`)
- J102: 1x03 pin connector (`Connector:Conn_01x03_Pin`)
- `Cabling` footprint placed on the board (purpose [UNKNOWN])
- Decorative "snail" artwork: `snail-10mm` placed on board, `snail-5mm` in the library
- Silkscreen text: "Spirulo", "Rev B", "V+"
- Board outline: round; sized up to ~22 mm in Rev B with two cutouts added to match the phial board (per commit d9261b1)
- The PCB embeds a 3D-model reference to the phial board's STEP export (see Known gaps — the reference is an absolute local path)
